# ThrashPlo

![ThrashPlo Logo](client/src/assets/images/img-logo.png)

## 🚀 Project Overview

**ThrashPlo** is an innovative waste management platform connecting citizens, communities, government, and recycling partners to solve Indonesia's critical waste challenges.

### The Problem

-   64M+ tons of waste annually in Indonesia with 30% improperly managed
-   Disconnected stakeholders in waste management ecosystem
-   Lack of accessible reporting and tracking tools
-   Inadequate sorting and recycling infrastructure

### Our Solution

ThrashPlo creates a complete ecosystem that empowers all stakeholders to collaborate efficiently in waste management:

## ✨ Key Features

-   **📱 Waste Reporting System** - Citizens report dumps with photos and location
-   **🔍 Verification & Tracking** - Real-time status updates from report to cleanup
-   **👥 Community Action** - Organize cleanups and manage volunteers
-   **♻️ Recycling Network** - Connect communities with recycling partners
-   **📊 Analytics Dashboard** - Track impact metrics for all participants

## 💡 Why ThrashPlo?

1. **Complete End-to-End Solution** - Reporting ➝ Cleanup ➝ Recycling in one platform
2. **Multi-Stakeholder Approach** - Four connected user roles creating true collaboration
3. **Incentive System** - Points and recognition for active participation
4. **Sustainability Focus** - Creates environmental, social, and economic benefits

## 🧩 User Flow

```
Citizen Reports ➝ Community Verification ➝ Cleanup Actions ➝
Sorting ➝ Recycling Transactions ➝ Proper Disposal
```

## 🔧 Tech Stack

**Frontend:** React/TypeScript, Context API, Framer Motion, Vite  
**Backend:** Node.js/Express, MongoDB, JWT Authentication, REST API

## 🌟 Impact

-   **Environmental:** Reduce illegal dumps, increase recycling rates
-   **Social:** Create volunteering opportunities, build awareness
-   **Economic:** Support recycling industry, create value from waste
-   **Governance:** Improve coordination between stakeholders

## 🧪 Installation

```bash
cd thrash-plo

# Start servers (requires Node.js 18+ and MongoDB)
cd server; npm install; npm run dev
cd client; npm install; npm run dev
```
